1. Career Mate AI – Intelligent Placement Preparation System

Career Mate AI is an AI-powered placement readiness platform designed to help students evaluate and improve their interview preparation.
The system integrates Resume ATS Analysis, Aptitude Tests, Technical Interviews, HR Round Evaluation, and Job Description Matching into a single intelligent dashboard.
--This project is built using Python, Streamlit, and Local LLM (Ollama – Llama 3.2) to provide a realistic interview preparation experience.f

------------------------------------------------------------------------------------------------------------------------------------------------------------
2.Features
✅ User Authentication (Login & Sign Up)
✅ Resume ATS Analysis with AI Feedback
✅ Aptitude MCQ Test with Automatic Scoring
✅ Technical Interview (MCQ + Theory Evaluation)
✅ HR Interview Simulation (Text / Voice Mode)
✅ Job Description Based Question Generation
✅ Placement Readiness Dashboard with Analytics
---------------------------------------------------------------------------------------------------------------------------------------------------------------
3.Project Architecture

The system follows a modular Streamlit architecture:

Career Mate AI
│
├── main.py                # Main controller & routing
├── user_registry.json     # User storage (local)
│
└── modules/
    ├── home.py            # Dashboard
    ├── resume_analyzer.py # ATS Resume Analysis
    ├── aptitude.py        # Aptitude MCQ Test
    ├── tech_interview.py  # Technical Interview
    ├── hr_bot.py          # HR Round Evaluation
    └── jd_extractor.py    # JD Based Questions
------------------------------------------------------------------------------------------------------------------------------
4. Tech Stack

Frontend & App Framework: Streamlit

AI Model: Ollama (Llama 3.2 – Local LLM)

Language: Python

Data Visualization: Plotly, Pandas

PDF Processing: PyPDF2

Voice Interaction: streamlit-mic-recorder

Version Control: Git & GitHub
---------------------------------------------------------------------------------------------------------------------------------------------------------
5. System Workflow

1️⃣ User logs into the system.
2️⃣ Resume is uploaded and evaluated for ATS compatibility.
3️⃣ User attempts Aptitude and Technical Interviews generated by AI.
4️⃣ HR module evaluates communication and answers.
5️⃣ Job Description module generates role-based questions.
6️⃣ Dashboard calculates overall placement readiness score.
------------------------------------------------------------------------------------------------------------------------------------------------------------
6 Dashboard Scoring Logic

Each module contributes to the final readiness score:

Resume ATS Score

Aptitude Test Score

Technical Interview Score

HR Round Score

JD Match Score

The dashboard dynamically calculates performance and highlights strengths and weaknesses.

💻 Installation & Local Setup
1️⃣ Clone the Repository
git clone https://github.com/Mandhalasushanth/AIcareermate.git
cd AIcareermate

2️⃣ Install Dependencies---
pip install -r requirements.txt

3️⃣ Install Ollama and Pull Model
ollama pull llama3.2


Make sure Ollama is running locally on:

http://localhost:11434

4️⃣ Run the Application
-- streamlit run main.py
